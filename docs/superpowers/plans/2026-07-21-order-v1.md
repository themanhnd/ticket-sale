# Order V1 Implementation Plan

**Goal:** Xây `order-service` V1 để tạo order, reserve vé và đọc trạng thái order.

**Architecture:** `order-service` nhận request qua Gateway, gọi đồng bộ `inventory-service` bằng `RestClient`, sau đó lưu order trong MySQL. Chưa thêm Kafka, Outbox, Idempotency hoặc Payment.

**Tech Stack:** Spring Boot 3.3.5, Spring MVC, RestClient, JPA, Flyway, MySQL, Eureka, Config Server, Docker Compose.

## Global Constraints

- Giữ Java release 21.
- Dùng package `com.ticketsale.order`.
- Dùng `ddl-auto: validate`.
- Migration tạo bảng, không dùng JPA auto-DDL.
- Comment code bằng tiếng Việt, file UTF-8 không BOM.
- Mỗi task phải build/test được trước khi sang task sau.
